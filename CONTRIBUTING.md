# Contributing

## Never commit real financial data

This repo is public. Keep personal portfolio data out of git:

- Put personal files under `/private/` or name them `*.local.json` — both
  are git-ignored.
- Only synthetic fixtures belong in tracked paths (e.g.
  `src/engine/scenarios/`).

## Branch and PR workflow

See `CLAUDE.md` for branch naming, PR, and changelog conventions.
